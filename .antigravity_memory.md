## 2. Architecture Technique Multi-Fournisseurs (v2.0.2)

### 🏛️ Fournisseurs Intégrés
1. **`undraw` (Approved, unDraw Open License) :**
   - 1800+ illustrations vectorielles conceptuelles.
   - Live API (`https://undraw.co/api/search`) avec isolation, timeout et fallback.
2. **`openpeeps` (Approved, CC0 1.0 Universal - Pablo Stanley) :**
   - Personnages vectoriels, postures, avatars, composition modulaire.
3. **`iradesign` (Approved, MIT License - Creative Tim) :**
   - Illustrations dégradées tech/fintech/devops, personnalisation fine des stops de dégradés (`ira-stop-start`, `ira-stop-end`).
4. **`storyset` (Manual-only, Freepik) :**
   - Respect strict des CGU (anti-scraping) : redirection vers liens officiels + snippets d'attribution légale.
5. **`drawkit` (Manual-only, DrawKit License) :**
   - Recherche guidée et conformité légale sans redistribution non autorisée.
6. **`manypixels` (Manual-only, ManyPixels License) :**
   - Catalogue guidé respectueux des conditions d'utilisation.

---

### 🧠 Les 6 Moteurs Cœurs
1. **`SearchEngine` :**
   - Analyse sémantique locale du contexte (composant `auth`, `404`, `empty`, `hero`, `team` ; ambiance `playful`, `tech` ; domaine `fintech`, `devops`).
   - Extraction automatique de palette depuis `tailwind.config.*` ou CSS vars (`--primary`).
2. **`ScoringEngine` :**
   - Score multi-critères sur 100 points (Sémantique 30 pts, Composant 25 pts, Style 15 pts, Couleur 10 pts, Format 10 pts, Licence 10 pts) avec `scoreBreakdown`.
3. **`CustomizationEngine` :**
   - Remplacement vectoriel précis des couleurs (primaire, secondaire, stops de dégradés).
   - Adaptation Dark Mode automatique.
   - Sanitisation SVG stricte (suppression `<script>`, handlers inline, `javascript:`).
   - Accessibilité automatique (`role="img"`, `<title>`).
4. **`IntegrationEngine` :**
   - Générateur de composants typés pour :
     - React TSX (`components/illustrations/<Name>.tsx`)
     - Next.js Image (`next/image`)
     - Vue 3 SFC (`<script setup lang="ts">`)
     - Svelte (`.svelte`)
     - Flutter (`SvgPicture.asset`)
     - HTML standard (`<img src="...">`)
   - Détection anti-doublon par hachage SHA256 (option `--force` disponible).
5. **`LicenseManager` :**
   - Validation et registre des licences (`approved` vs `manual_only`).
   - Génération de snippets d'attribution légale.
   - Audit complet via `npx tidjan-autopic audit`.
6. **`FallbackManager` & `CacheManager` :**
   - Bascule en cascade intelligente (`undraw` ➔ `openpeeps` ➔ `iradesign`).
   - Métriques de santé des providers (tentatives, succès, latence, erreurs).
   - Cache disque et mémoire avec TTL.

## 3. Commandes CLI
```bash
# Recherche intelligente contextuelle
npx tidjan-autopic smart "<concept>" [--provider <id>] [--framework <f>] [--color <hex>] [--dark] [--force] [--json]

# Recherche multi-fournisseurs directe
npx tidjan-autopic search "<query>" [--provider <id>] [--json]

# Liste et état des fournisseurs
npx tidjan-autopic providers

# Audit de conformité des licences
npx tidjan-autopic audit

# Téléchargement direct d'un SVG
npx tidjan-autopic download "<query>" [dir] [--provider <id>]
```
