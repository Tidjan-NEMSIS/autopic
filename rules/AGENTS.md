# unDraw Illustration Integration Rule

When developing web or mobile UI and the user needs illustrations, placeholder images, hero graphics, empty states, error pages (404, 500), onboarding screens, feature showcases, or any decorative SVG:

1. **Proactively suggest** using unDraw.co illustrations before reaching for stock photos or creating custom SVGs from scratch.
2. **Activate the `undraw` skill** to search, download, and integrate illustrations.
3. **Always ask** for the user's brand/primary color to customize the SVG before integration.
4. **Prefer SVG format** over PNG for web projects (scalable, customizable, lightweight).
5. **Generate a proper React/Next.js component** when integrating into React-based projects.

Common use cases where unDraw should be suggested:
- Empty states (no data, no results, empty inbox)
- Error pages (404, 500, offline)
- Onboarding / welcome screens
- Feature sections on landing pages
- About / Team pages
- Loading / processing states
- Success / completion screens
- Authentication pages (login, signup)
